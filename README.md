# PG Complaint Management System

## About the Project

This project is a simple PG Complaint Management System.

It allows residents to submit complaints about issues such as electricity,
plumbing, water supply, internet and other facilities.

## Features

- Submit a complaint
- View submitted complaints
- Search complaints
- View individual complaints
- Update complaint status
- Delete complaints
- Basic input validation

## Technologies Used

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js
- REST API
- JSON
